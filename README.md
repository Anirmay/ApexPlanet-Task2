# ApexPlanet Internship - Task 2

This project demonstrates advanced HTML, CSS, and JavaScript fundamentals for a responsive web page.

## Project structure

- index.html
- style.css
- script.js

## Included features

- Responsive navigation using Flexbox
- CSS Grid content cards for desktop, tablet, and mobile layouts
- Contact form with required field validation and email format validation
- Success message for valid submission using JavaScript
- Dynamic to-do list with add and delete behavior
- Empty task validation and user-friendly feedback

## How to run

Open the `index.html` file in any web browser, or serve the project with a local HTTP server.

Example:

```bash
cd Task-2
python -m http.server 8000
```

Then visit: http://localhost:8000/
